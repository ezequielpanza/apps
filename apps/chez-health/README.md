# Chez Health

PWA de recordatorios semanales para sumar variedad de grupos de alimentos.

## Publicación

- Carpeta: apps/chez-health
- Proyecto Cloudflare Pages: chez-health
- URL: https://chez-health.pages.dev
- Tecnología: HTML, CSS y JavaScript sin dependencias
- Build: no requiere
- Carpeta de salida: apps/chez-health
- Workflow: .github/workflows/deploy-chez-health.yml

## Uso

Las marcas se guardan localmente en el navegador. La semana se calcula con la zona horaria de Santo Domingo y la lista comienza vacía cada lunes. La aplicación funciona sin conexión después de su primera carga.

La lista ofrece ideas generales de variedad y no estima nutrientes ni sustituye orientación personalizada.
