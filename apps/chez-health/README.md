# Chez Health

PWA de seguimiento semanal de alimentos para acompañar una alimentación variada. Cada casilla representa una ingesta sugerida y las marcas se guardan en el dispositivo.

## Publicación

- Carpeta: apps/chez-health
- Proyecto Cloudflare Pages: chez-health
- URL: https://chez-health.pages.dev
- Tecnología: HTML, CSS y JavaScript sin dependencias
- Build: no requiere
- Carpeta de salida: apps/chez-health
- Workflow: .github/workflows/deploy-chez-health.yml

## Seguimiento semanal

La semana va de lunes a domingo según la fecha local del dispositivo. Las marcas se reinician al cambiar la semana, al abrir la app o al volver a ella después del lunes. La aplicación funciona sin conexión después de su primera carga.

Las frecuencias de carnes y otros alimentos son referencias generales elegidas para organizar variedad semanal. No representan una prescripción individual ni sustituyen la orientación de un profesional de nutrición.
