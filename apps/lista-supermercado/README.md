# La lista · Chez Team

Webapp/PWA de supermercado para uso móvil. Permite agregar productos y cantidades, agrupar automáticamente por categoría, marcar y recuperar compras, borrar productos, limpiar comprados y reutilizar productos del historial. Funciona sin conexión después de la primera visita.

La información se guarda en `localStorage` del navegador del dispositivo. No hay cuenta ni sincronización entre teléfonos en esta versión; borrar los datos del sitio elimina la lista.

Publicación: proyecto Cloudflare Pages `lista-supermercado`, carpeta `apps/lista-supermercado`, workflow `.github/workflows/deploy-lista-supermercado.yml`, URL `https://lista-supermercado.pages.dev`.
