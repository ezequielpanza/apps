# Contextum plugin

Contextum brings a temporary, user-authorized device context snapshot into ChatGPT and Codex through the remote MCP endpoint at `https://contextum.pages.dev/mcp`.

## Current capability

The plugin is read-only. It can retrieve coordinates, GPS accuracy, movement data, an active note, runtime state, and snapshot freshness using an 8-character temporary pairing code generated by Contextum.

## Tools

- `get_current_context`: preferred tool with freshness metadata.
- `get_context`: legacy compatibility alias.

## ChatGPT registration

For private testing, register the remote MCP endpoint in ChatGPT Developer Mode. ChatGPT assigns a technical app identifier during registration. Add that identifier later in `.app.json` before packaging the ChatGPT app binding for distribution.

## Privacy

Context snapshots are opt-in and temporary access codes expire. See `https://contextum.pages.dev/privacy.html`.
